# Contributing

Small, evidence-backed contributions are welcome through GitHub issues and pull
requests.

Before proposing a new adapter, metric, or manifest contract:

1. identify an exact public protocol or upstream revision;
2. separate prediction, gold, and evaluator-generated artifacts;
3. add positive, negative, and metamorphic controls;
4. register deterministic expected findings;
5. document the claim boundary; and
6. run the full Rust and Python checks.

Do not submit private prompts, proprietary repositories, credentials, personal
data, unpublished research, paid-service output that cannot be redistributed,
or claims of external impact without independent evidence.

Contributions intentionally submitted for inclusion are accepted under the
project's Apache-2.0 license. Submission does not guarantee review, acceptance,
release, endorsement, or compatibility.
